# Hydrostor

> Hydrostor is a Canadian long-duration energy storage developer (founded 2010, Toronto, with offices in
> Denver, Melbourne and Adelaide) that builds and operates Advanced Compressed Air Energy Storage (A-CAES)
> facilities. It publishes no developer program, no SDKs and no API of its own. The only machine-readable
> interface it exposes is the WordPress core REST content API behind hydrostor.ca — anonymous,
> read-only, and carrying the A-CAES project portfolio, the newsroom archive and the media library.
> This file was generated by API Evangelist on 2026-08-22 from artifacts derived from that live surface;
> Hydrostor does not publish an llms.txt (https://hydrostor.ca/llms.txt returns 404).

Base URL: https://hydrostor.ca/wp-json
Authentication: none for reads. Writes require a WordPress application password with no public issuance path.
Rate limits: none advertised. No RateLimit-*, X-RateLimit-* or Retry-After header is returned. Self-throttle.

## APIs

- [Projects API](https://hydrostor.ca/wp-json/wp/v2/project): The A-CAES project portfolio — Goderich, Willow Rock, Silver City, Quinte, Wellington, Copper Valley. 6 records. The only Hydrostor-specific resource on the surface.
- [Posts API](https://hydrostor.ca/wp-json/wp/v2/posts): Newsroom archive — 172 posts across Press Release (54), Featured Coverage (96) and Insights (24).
- [Pages API](https://hydrostor.ca/wp-json/wp/v2/pages): 22 static marketing and policy pages.
- [Media API](https://hydrostor.ca/wp-json/wp/v2/media): 736 attachments with generated size variants.
- [Taxonomy API](https://hydrostor.ca/wp-json/wp/v2/categories): Newsroom categories (4 terms). The tag, project_category and project_tag vocabularies are registered but carry zero terms.
- [Search API](https://hydrostor.ca/wp-json/wp/v2/search): Cross-content search over 200 objects, returning id/title/url/type/subtype.
- [Discovery API](https://hydrostor.ca/wp-json/): Self-describing route index — 340 routes across 18 namespaces, plus registered types, taxonomies, statuses and public authors.
- [oEmbed API](https://hydrostor.ca/wp-json/oembed/1.0/embed): oEmbed 1.0 rich metadata for any hydrostor.ca URL.
- [SEO Metadata API](https://hydrostor.ca/wp-json/yoast/v1/get_head): Rendered head metadata and parsed schema.org JSON-LD for any hydrostor.ca URL.

## Not available

- No developer portal, documentation, API reference, getting-started guide or Postman collection.
- No OpenAPI, AsyncAPI, GraphQL SDL or WSDL published by Hydrostor. The specs above were derived by API Evangelist from the live surface.
- No MCP server (mcp.hydrostor.ca does not resolve; /.well-known/mcp returns 404).
- No A2A agent card (/.well-known/agent-card.json and /.well-known/agent.json both return 404).
- No /.well-known/ documents at all, no security.txt, no bug bounty, no trust center.
- No SDKs or CLI in any package registry, and no GitHub organization.
- No webhooks, events or streaming surface.
- No pricing, plans or signup — Hydrostor sells storage capacity under negotiated contracts, not API access.
